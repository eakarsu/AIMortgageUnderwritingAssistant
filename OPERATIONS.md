# Operator runbook

Install explicitly, review migrations, and apply with `DATABASE_URL=... ./scripts/migrate.sh`; startup never creates schema, seeds, installs, kills ports, or starts PostgreSQL. Configure a unique 32+ character JWT secret and keep experimental/provider surfaces disabled.

Only reconciled versioned inputs may calculate DTI/LTV. Approval/decline needs independent explained review and immutable evidence; locks need pricing receipts; reversals need correction references. Banking, title, appraisal, CRM, market, document, e-sign, and filing providers remain blocked without credentials and reconciliation fixtures. This tool is advisory: a licensed underwriter owns the decision and fair-lending review.
